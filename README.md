# HotelPro - Full-Stack Hotel Booking & Management Solution

HotelPro is a comprehensive hotel operations and guest booking management system built with React, TypeScript, Tailwind CSS, and Node.js.

## Features

- **Guest Portal**: Browse suites, filter by price/category, make room reservations, and manage active bookings.
- **Front Desk Management**: Real-time room status tracking, instant check-in/check-out processing, and guest keycard assignment.
- **Housekeeping & Operations**: Task allocation for room cleaning, status updates (dirty, cleaning, inspected), and maintenance tracking.
- **Admin & Analytics**: Dashboard metrics, revenue breakdowns, operational logs, and hotel configuration management.

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS, Lucide React
- **Build Tool**: Vite
- **Deployment**: Vercel
